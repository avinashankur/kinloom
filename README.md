Global shortcuts (always work):

- `+` or `=`: Zoom in
- `-`: Zoom out
- `F` or `0`: Fit the entire tree perfectly to the screen

Person-specific shortcuts (when you have a person clicked/focused):

- `Enter`: Opens the "Edit Person" dialog
- `Shift + Enter`: Directly opens the "Add Relationship" dialog with "Child" already selected
- `Ctrl + Enter` (or `Cmd + Enter` on Mac): Directly opens the "Add Relationship" dialog with "Spouse" already selected
- `Delete` or `Backspace`: Immediately deletes the person (and their branch)
- `Escape`: Deselects the person
